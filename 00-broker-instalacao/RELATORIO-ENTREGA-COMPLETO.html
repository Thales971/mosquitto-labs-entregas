1. O que e o Mosquitto e por que precisamos dele

O Mosquitto e um broker (corretor) de mensagens MQTT — a central de correios para IoT.

  • O ESP32 (remetente) envia dados dos sensores para o Mosquitto.
  • O aplicativo no celular (receptor) conecta ao Mosquitto para receber as mensagens.
  • O Mosquitto e o intermediario que garante a entrega.

3. Instalacao do Mosquitto (Windows)

Eclipse Mosquitto instalado em C:\Program Files\mosquitto\ como servico Windows mosquitto, inicio Automatic.

Verificacao (como no guia):

net start | findstr Mosquitto
sc query mosquitto

Resultado: Mosquitto Broker em execucao (ESTADO 4 RUNNING).

4. Configuracao basica (conexoes anonimas — lab)

Arquivo: C:\Program Files\mosquitto\mosquitto.conf

listener 1883
allow_anonymous true
  • listener 1883 — escuta na porta padrao MQTT.
  • allow_anonymous true — permite conexao sem usuario/senha (somente lab local).

Arquivo salvo com elevacao de administrador; servico reiniciado.

5. Teste do servidor (linha de comando)

cd "C:\Program Files\mosquitto\"
mosquitto_sub -t "teste/mensagem"

cd "C:\Program Files\mosquitto\"
mosquitto_pub -t "teste/mensagem" -m "Ola do Mosquitto!"

Resultado: PASS — Janela 1 recebeu Ola do Mosquitto!.
